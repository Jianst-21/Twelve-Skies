## Git Commit Guidelines
- Always write commit messages in English.
- Keep commit messages very brief, concise, and high-level (do not provide overly detailed descriptions).
- Standard formats:
  - `feat: add feature`
  - `fix: bug fixes`
  - `update: ui improvements`
  - `refactor: clean up`
  - `chore: update config`
